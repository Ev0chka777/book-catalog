#Каталог книг

#Возможности

- Каталог книг с обложками, авторами, жанрами и описаниями
- Адаптивная вёрстка (мобильные, планшеты, десктоп)
- Регистрация и авторизация пользователей
- Роли: пользователь и администратор
- CRUD-операции (создание, редактирование, удаление книг) — доступны только администратору
- Защита от SQL-инъекций (подготовленные запросы PDO)
- Хеширование паролей через bcrypt

#Стек

- **HTML5, CSS3, Bootstrap 5.3** — фронтенд
- **PHP 8.2** — серверная логика
- **PostgreSQL 17** — база данных
- **Apache 2.4** — веб-сервер (через XAMPP)

## Установка и запуск

### Требования

- XAMPP (Apache + PHP 8.2+)
- PostgreSQL 16+
- Расширение PHP `pdo_pgsql`

### Шаги

1. Установить PostgreSQL, создать базу `book_catalog`.
2. Выполнить SQL-скрипт для создания таблиц `books` и `users`.
3. Установить XAMPP, включить расширение `pdo_pgsql` в `php.ini`.
4. Скопировать проект в `C:\xampp\htdocs\book-catalog`.
5. В `db.php` указать правильный пароль PostgreSQL.
6. Запустить Apache, открыть `http://localhost/book-catalog/`.

## Схема базы данных

### Таблица `books`

| Поле | Тип | Описание |
|---|---|---|
| id | SERIAL PRIMARY KEY | Уникальный номер |
| title | VARCHAR(200) NOT NULL | Название |
| author | VARCHAR(150) NOT NULL | Автор |
| year | INTEGER | Год издания |
| genre | VARCHAR(100) | Жанр |
| description | TEXT | Описание |
| cover_url | TEXT | Ссылка на обложку |

### Таблица `users`

| Поле | Тип | Описание |
|---|---|---|
| id | SERIAL PRIMARY KEY | Уникальный номер |
| username | VARCHAR(50) UNIQUE | Логин |
| email | VARCHAR(150) UNIQUE | Email |
| password_hash | VARCHAR(255) | Хеш пароля (bcrypt) |
| role | VARCHAR(20) | Роль: `user` или `admin` |

## Безопасность

- Все SQL-запросы используют **подготовленные запросы** (PDO prepared statements) — защита от SQL-инъекций.
- Пользовательский ввод экранируется через **htmlspecialchars()** — защита от XSS.
- Пароли хранятся в виде **bcrypt-хешей** (`password_hash` / `password_verify`).
- Серверная проверка ролей в CRUD-эндпоинтах.
